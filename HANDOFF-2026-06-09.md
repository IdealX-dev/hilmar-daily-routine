## 6. Common gotchas surfaced this session

**PowerShell module-name quirk** — `deploy\sync_now.cmd` from any directory fails with "module 'deploy' could not be loaded". Use the full path with `&`:
```powershell
& "$env:USERPROFILE\OneDrive - IdealX\claude\PROJECT HILMAR\hilmar-daily-routine\deploy\sync_now.cmd"
```

**Select-String regex pipes** — `Select-String "A\|B"` doesn't work. Use `-Pattern "A|B"`:
```powershell
Select-String -Pattern "QC-054|QC-055" path\to\file.py
```

**Wrapper feels "hung"** — `patch_carriers` is the slow step (4-pass enrichment, 1-2 minutes). Don't hit Ctrl-C. The wrapper writes to `reports\run-log.txt`, not stdout — most output is invisible until done.

**Wrapper exits instantly** — that's idempotency: today's emails already shipped, every send step short-circuits via `reports\sent-YYYY-MM-DD.flag`. Check the log for `Pipeline exit code: 0` to confirm it actually ran.

**Git-in-OneDrive ref corruption** — `Deletion of directory '.git/refs/remotes/origin/...' failed. Should I try again? (y/n)`. **Answer `n` repeatedly to break out, then run `git config windows.appendAtomically false`.** The pipeline doesn't care about reflog state, just file contents — verify with `Select-String "PENDING_WINDOW_HOURS = " scripts\core.py` etc.

**GH heartbeat rate limit** — `gh workflow run` hitting "API rate limit already exceeded for user ID 272622394" is a personal-token limit (5000/hr). Cosmetic, doesn't affect pipeline. Resets in an hour.

**Wrapper drift** — the scheduled task runs `PROJECT HILMAR\deploy\run_daily_laptop.cmd` (outside the repo). The wrapper's Step 0 git-pull copies `scripts\*.py` but **not** itself (can't overwrite while executing). `sync_now.cmd` now also copies `deploy\*.cmd` to fix this permanently. After any wrapper change, run `sync_now.cmd` once.
